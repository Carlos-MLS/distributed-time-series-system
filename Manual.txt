Compilar- 
javac src/**/*.java

Executar Server (com parâmetros D e S opcionais) - 
java -cp src server.Server [D] [S]
Exemplo: java -cp src server.Server 50 10

Executar Cliente Interativo -
java -cp src apps.ClienteInterativo
(Após login, permite adicionar eventos, consultar agregações, filtrar eventos e usar barreiras)

Executar Cliente Testes (com opções):
java -cp src apps.ClienteTestes [opção]
  1 - Testes Funcionais (Fases 1-7)
  2 - Testes de Performance (Inserção Massiva)
  3 - Testes de Escalabilidade (Múltiplos Clientes + Cliente Multi-threaded)
  4 - Testes de Robustez (Cliente Lento)
  5 - Executar TODOS os testes
